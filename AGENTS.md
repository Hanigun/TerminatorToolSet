## Коммиты (ВАЖНО)
Все изменения коммитить СРАЗУ, не откладывая и не копя в дереве:
- закончил задачу — закоммить (тематическими коммитами, по областям);
- в репозитории должны лежать только чистые файлы самой программы
  (см. `.gitignore`: доки, планы, гейты, тесты, раннеры не трекаются);
- перед коммитом прогнать проверки (`node scripts/verify-ui-wiring.mjs`,
  `python scripts/verify_history.py`, `node --check` для тронутых JS);
- exe НЕ пересобирать без явной просьбы; пользователь запускает из консоли
  (`python main.py`).

## Что где
- `main.py` / `app.py` — запуск и Flask-бэкенд (тонкая фабрика, роуты в `terminator_toolset/api/`)
- `terminator_toolset/` — домен, сервисы, инфраструктура
- `static/js/`, `static/css/`, `templates/` — фронт (классические скрипты, общий скоуп)
- `locales/` — строки ru/en/de/zh (ключи синхронно во всех четырёх файлах)
- `assets/` — шиппящиеся ассеты (трекаются); `assets/CustomImages/` — рантайм-кэш (в игноре)
- `UprisingPresets/`, `UprisingRandomizer/` — встроенные данные, трекаются и пакуются в сборку
